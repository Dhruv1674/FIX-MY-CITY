# FixMyCity Connect — Find Your People

A beginner-friendly static web prototype adapted from the original FixMyCity civic reporting concept toward a community-connection idea inspired by the visible AFFECIO HACKS '26 option **PS03: Find your people**.

## What it does
- Discover local interest communities and search/filter by interest.
- Join or leave communities.
- Browse sample neighborhood meetups and mark interest.
- Create a meetup that appears in the list.
- Save joined groups, attendance, and new meetups in browser `localStorage`.
- Responsive layout for laptop and mobile.

## Run it
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Try joining a group, marking interest in a meetup, and creating your own meetup.

## Important limitations
- This is a frontend demo. It does not have accounts, verified identities, messaging, a real location service, a backend database, or moderation.
- Sample groups and meetups are illustrative; they are not confirmed real events.
- Data is stored only in the current browser. It will not sync between devices or users.
- This adapts the project based on the PS03 title shown in the screenshot. Before final submission, compare it with the complete official PS03 problem statement and adjust the features/wording to match the actual requirements.
- For a shared demo URL, deploy the folder using GitHub Pages or another static host.
